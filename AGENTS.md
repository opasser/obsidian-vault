# AGENTS.md

Правила работы с этим Obsidian vault.

## Язык

- Отвечать просто, ясно и кратко.
- Если пользователь пишет по-русски, отвечать по-русски.
- Если пользователь просит текст на английском, писать простым английским для non-native speakers.

## Структура vault

- `Apple Notes/` — импортированные заметки из Apple Notes.
- `палийский канон/` — рабочая папка по палийскому канону.
- `палийский канон/термины.md` — главный индекс терминов.
- `палийский канон/описания терминов/` — отдельные страницы терминов.

## Правила для заметок

- Не смешивать импортированные заметки и готовую структуру.
- Не удалять и не переименовывать заметки без прямой просьбы.
- Для терминов использовать Obsidian-ссылки:

```md
[[палийский канон/описания терминов/dukkha|dukkha]]
```

- Один термин = одна отдельная заметка.
- `термины.md` использовать как таблицу-индекс:

```md
| Pāli | Перевод | Описание |
|---|---|---|
| dukkha | страдание, неудовлетворенность | [[палийский канон/описания терминов/dukkha|dukkha]] |
```

## Плагины Obsidian

Уже есть полезные плагины:

- Importer — импорт из Apple Notes.
- Linter — единый стиль Markdown.
- Omnisearch — быстрый поиск.
- Obsidian Git — сохранение изменений через Git.
- Excalidraw — схемы и рисунки.
- Highlightr — выделение текста.

## Главная цель

Организовать заметки по палийскому канону:

- собрать термины;
- связать Pāli слово, перевод и полное описание;
- постепенно переносить полезные заметки из `Apple Notes/BUDISM/` в структуру `палийский канон/`.
